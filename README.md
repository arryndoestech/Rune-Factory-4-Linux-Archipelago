# Rune-Factory-4-Linux-Archipelago
A linux installer for Happyhappyism's archipelago for [Rune Factory 4 Special](https://github.com/Happyhappyism/Rune-Factory-4-Archipelago).  

## How to install
Make sure you have steam installed in it's default location ``$HOME/.steam``.  
Also make sure you have Rune Factory 4 Special installed through steam and have started it at least once.  
Then copy and paste the following command into your terminal:

```bash
curl -fsSL "https://raw.githubusercontent.com/arryndoestech/Rune-Factory-4-Linux-Archipelago/main/install_archipelago.sh" | bash
```  
After that you follow the instructions seen on the screen after the install is done.
